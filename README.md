# Deep Learning Specialization

This repository documents my learning journey through the
[Deep Learning Specialization](https://www.deeplearning.ai/courses/deep-learning-specialization/)
by DeepLearning.AI.

It contains my course labs, programming assignments, lecture notes, and study
materials as I work through the specialization. The goal is to keep a clear,
organized record of the concepts I practice, the notebooks I complete, and the
main ideas I want to revisit later.

## Contents

## How to Use This Repository

Most lab files are Jupyter notebooks. To explore them locally:

```bash
git clone <repo-url>
cd Deep-Learning-Specialization
jupyter notebook
```

Then open the notebooks inside the `Labs/` directory.

Some assignments include datasets, helper scripts, images, or test files in the
same folder as the notebook. Keep those files together when running a lab.
